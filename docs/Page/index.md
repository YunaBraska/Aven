# Aven

A quiet macOS menu-bar companion for spoken project work.

[Documentation](documentation.html) | [Install](install.html) | [Source](https://github.com/YunaBraska/Aven)

## What it does

- Captures a held-key voice prompt without a wake word or permanent window.
- Keeps a continuing conversation while preserving project context.
- Supports typed input, dropped files and concise spoken progress updates.
- Records meetings only after a clear confirmation.

## Availability

Aven is still under active development. The external macOS delivery channel is being prepared, but there is not yet a supported public download.

## Requirements

Aven supports macOS 14 and later.
