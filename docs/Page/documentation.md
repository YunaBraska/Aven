<section class="page-heading">
  <p class="eyebrow">Aven help</p>
  <h1>Use Aven without losing your place.</h1>
  <p>Aven is designed around deliberate voice input and one ongoing project conversation.</p>
</section>

<ul class="doc-list">
  <li><strong>Start a conversation</strong><p>Hold your configured shortcut, speak, then release it. Aven transcribes the prompt and sends it through the installed Codex client.</p></li>
  <li><strong>Continue the work</strong><p>Additional speech, typed input and dropped files are kept in order while the current conversation is still running.</p></li>
  <li><strong>Record a meeting</strong><p>Choose the recording action and confirm only after informing participants. A visible recording indicator remains while capture is active.</p></li>
  <li><strong>Review privacy</strong><p>Read which data stays local, what is forwarded through Codex and how microphone access is used.</p><a href="privacy.html">Privacy details</a></li>
</ul>

<section class="section">
  <h2>Need help?</h2>
  <p class="section-intro">Report a reproducible problem in the project issue tracker. Do not include credentials, private transcripts or meeting audio.</p>
