# Web research

Use current web sources only when freshness, uncertainty, recommendations, risk, or requested
attribution makes them material. Prefer primary and authoritative sources, then independent sources
when comparison or external verification adds value. Open the supporting page; do not rely on search
snippets.

State the relevant date and distinguish sourced facts from inference. For changing claims, compare
publication date with the date the event or rule took effect. Cite the page nearest the claim and use
short paraphrases instead of long quotations.

Keep research proportional to the decision. Stop when additional sources are unlikely to change the
answer, and say what remains uncertain. If native web access is unavailable, explain the limitation
instead of presenting remembered current facts as verified.
